# Labelled real-world samples for testing an actual detector.
#
#   ai   <url>    known AI-generated
#   real <url>    known real (camera) image
#
# `python3 test/make_fixtures.py --fetch` downloads them into
# test/site/fixtures/external/{ai,real}/ (git-ignored). Then:
#   node test/accuracy.mjs                     # score them with the local detector
#   node test/accuracy.mjs --provider sightengine
# You can also drop files straight into those folders. Check each file's licence before sharing.
#
# Good sources: Wikimedia Commons "Category:AI-generated images" (licence on each file page),
# images you generate yourself, and your own camera photos.
